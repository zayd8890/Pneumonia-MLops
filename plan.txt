| **Language**                   | **Python**                                             | Go, Java                                  | Best fit because ML, data processing, PyTorch, FastAPI and MLOps tooling are heavily Python-oriented. Go can come later for infrastructure services.                                  |
| **ML framework**               | **PyTorch**                                            | TensorFlow/Keras, JAX                     | Excellent computer-vision ecosystem and gives you low-level understanding rather than hiding the training process behind a high-level framework.                                      |

| **Experiment tracking**        | **MLflow**                                             | Weights & Biases, Neptune                 | Open-source/self-hostable and gives you experiments, artifacts and model registry in one system. Very appropriate for learning the model lifecycle.                                   |
| **Data/model versioning**      | **DVC**                                                | Git LFS, LakeFS                           | DVC fits naturally with Git and ML pipelines and forces you to learn reproducible data/version management rather than treating datasets as static files.                              |

| **Containerization**           | **Docker**                                             | Podman                                    | Docker has an enormous ecosystem and integrates naturally with your CI/CD, registry and Kubernetes workflow.                                                                          |
| **Local orchestration**        | **Docker Compose**                                     | Podman Compose, Minikube                  | Extremely useful for developing the complete distributed stack before moving it to Kubernetes.                                                                                        |
